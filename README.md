# Simple Platformer

A simple 2D platformer built in **Godot** using **C#**, based on Brackeys' beginner Godot platformer tutorial. The project serves as a learning exercise for understanding platformer mechanics, physics, player movement, and Godot's workflow. :contentReference[oaicite:0]{index=0}

## Features

- Player movement
- Jump mechanics
- Basic platforming gameplay
- Built with Godot and C#
- Beginner-friendly project structure

## Getting Started

### Requirements

- Godot 4.x with .NET support
- .NET SDK compatible with your Godot version

### Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/simple-platformer.git
   ```

2. Open the project in Godot.

3. Build the C# solution if prompted.

4. Press **F5** to run the game.

## Controls

| Action | Key |
|----------|-----|
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
| Jump | Space |
